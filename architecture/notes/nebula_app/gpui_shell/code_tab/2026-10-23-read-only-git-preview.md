# 复用手机 Git 读取合同的桌面差异预览

## Status

Implemented in source; native interaction acceptance pending.

## Context

用户主要查看 Agent 修改后的差异。原变更列表打开普通文件，无法直接看新增、
删除和暂存范围。手机 Git 接口已有受限读取，可复用其命令与错误合同。

## Evidence

`runtime_api/git.rs` 已处理原始路径、重命名两端、新文件、无初始提交、命令时限
及输出上限。现有代码编辑器已启用 tree-sitter diff，并支持只读呈现与虚拟化。

## Decision

桌面变更列表单击普通 Git 文件打开只读 diff 标签；暂存区和工作区按独立键复用
标签。冲突继续走合并器，SVN 保留原路径。行内写操作截断点击传播，避免误开预览。
桌面状态增加 `--untracked-files=all`，使新文件直接按文件而非整个目录展示。

`code_tab/diff.rs` 拥有预览状态、输入与加载任务。数据读取通过只读 read_diff
适配调用现有 Git 执行器，不创建临时 diff 文件，不调用外部差异工具，不改源码。
使用既有 25 秒总时限和 256 KiB 输出上限，显示过大、超时、过期、忙碌和编码错误。
关闭标签取消 UI 等待；后台操作结束后只更新仍存在的实体。刷新按钮重新读取。

## Rejected alternatives

- 自行比较当前文件与 HEAD：会忽略暂存范围、重命名与新仓库语义。
- 新造文本列表、高亮和滚动器：已有虚拟代码编辑器覆盖这些职责。
- 将 diff 落成临时可编辑文件：引入保存、清理和错误写回路径。

## Consequences

预览上限沿用共享后端，超限需要打开源文件查看。预览是读取时的差异快照，
通过刷新或重新选择更新，不宣称对 Agent 的每次写入实时增量同步。

## Validation

核对了实际调用链、只读执行范围与行内按钮传播。源码格式解析和架构检查通过；
未在本轮构建或运行原生产品，未据此声称视觉、键盘或真实仓库预览已验收。

## Supersedes

None.

## Revisit when

需要更大的差异、增量更新、分栏 diff 或跨仓库预览标签管理时。
