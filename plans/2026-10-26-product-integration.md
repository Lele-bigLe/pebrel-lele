# Pebrel Lele：功能整合与开发清单

更新：2026-10-26。用户已同意合并既有需求与本轮功能建议并开始开发。

## 产品边界

Pebrel 是轻量的项目、终端会话和 Agent 结果审阅工作台。主要适配 Codex，兼顾
Claude Code、Gemini、OpenCode。沿用 Rust/GPUI 与现有平台能力。

CC Switch 继续负责供应商、账号配置、模型路由、MCP、Skills 和规则；Pebrel
不复制这些配置。用量改为读取智能体本机原生记录，官方额度与本机 token 分开。
手机端复用现有控制入口，不再引入另一套远程控制服务。

## 去重与共用原则

- 项目库是项目名称/分组/收藏的唯一数据源；目录、分支和会话是其关联信息。
- 会话定位使用来源 + 原生 session ID，运行态再用窗口/pane ID；不靠标题猜同一会话。
- 任务通知中心复用既有状态与通知，不增加另一套 Agent 完成/批准判定。
- Git 工作区差异不默认等于某个 Agent 的本轮修改；精确归属需要独立 Worktree
  或明确任务基线。初版批注使用当前差异快照，变更后应提示重选。
- 审阅与选区反馈共用既有目标会话选择/输入路径，不另造模型调用和供应商配置。
- 项目启动模板定义布局/启动；收藏命令定义可反复调用的单个命令，避免两套工作流引擎。
- 普通 Shell 输出按已存在的命令边界增强操作；完整块式渲染不是首轮目标。
